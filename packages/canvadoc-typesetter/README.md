# canvadoc-typesetter

Deterministic Markdown + math typesetter that shares one layout pipeline for Canvas preview and PDF export.

## Docs

- Public API contract: `PUBLIC_API.md`
- Integration guide: `INTEGRATION.md`
- Changelog: `CHANGELOG.md`

## Local Package Commands

```bash
pnpm run build
pnpm run typecheck
pnpm run test
pnpm run api:check
```
