Output rules:
- Return Markdown only.
- Do not wrap the full answer in triple backticks.
- Use only these features: headings, paragraphs, bold/italic text, lists, blockquotes, tables, fenced code blocks, horizontal rules, images, inline math, and display math.
- Use heading order in sequence: #, then ##, then ###.
- Keep blank lines between major blocks.
- Keep tables simple and readable; avoid nested tables.
- For math, use $...$ inline and $$...$$ for display equations.
- Avoid raw HTML, footnotes, and plugin-specific Markdown extensions.
- Keep line lengths reasonable for stable pagination.

Goal:
- Produce clear, printable Markdown that renders cleanly in MD2PDF.

Getting Started

  1. Load one or more markdown files with Upload, or start typing immediately.
  2. Choose the active document in Open Files (left panel).
  3. Set Font, Margin, and Page size in the toolbar.
  4. Use preview controls: Fit Width, Fit Page, Zoom +/-.
  5. Click Export PDF and choose current file or all open files.

Tip: keep Fit Width while editing, and switch to Fit Page for final visual QA.

Formatting Guide

  • Use heading levels in order: #, then ##, then ###.
  • Leave a blank line between blocks (paragraphs, lists, tables, code).
  • Prefer short paragraphs for cleaner pagination.
  • Use two trailing spaces for explicit line breaks when needed.
# H1 Title
## H2 Section
### H3 Subsection

Paragraph one.

Paragraph two with **bold** and *italic* text.

Use `inline code` for command names and identifiers.

Math and Matrices

Use single dollars for inline math and double dollars for display math blocks.

Inline:
The energy relation is $E = mc^2$.

Display:
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

Aligned system:
$$
\begin{aligned}
2x + y &= 5 \\
x - y &= 1
\end{aligned}
$$

Matrix:
$$
\begin{bmatrix}
1 & 2 \\
3 & 4
\end{bmatrix}
$$

Piecewise:
$$
f(x)=
\begin{cases}
x^2, & x \ge 0 \\
-x,  & x < 0
\end{cases}
$$

If a matrix appears wrong, check that row breaks use \\ inside the math block.

Navigation and Focus Sync

  • Click in markdown to focus the corresponding rendered block in preview.
  • Click in preview to jump back to matching source lines in the editor.
  • Repeated clicks in the same section suppress extra pulse animations when views are unchanged.
  • Use pane dividers to optimize layout while reviewing dense content.

Pagination Tips

  • Keep headings close to their first paragraph.
  • Prefer one table per topic rather than very large tables.
  • Break oversized code samples into logical chunks.
  • Use sectioning with ## and ### to stabilize page flow.
  • Use medium margins and 12px font for balanced readability and page density.

Export Workflows

  • Current file: generates one PDF using the active markdown filename.
  • All open files: generates one PDF per file and downloads a single ZIP.
  • Export is headless (no browser print dialog).
  • The progress panel shows completed count, active step, file timing, and total timing.

Troubleshooting

  • Blank preview: verify the file has content and valid markdown structure.
  • Math not rendering: ensure delimiters are correct and braces are balanced.
  • Unexpected page breaks: split long tables/code blocks into smaller sections.
  • Wrong export names: rename files in Open Files (affects downloads only).
  • Layout feels cramped: resize the sidebar and pane dividers to your workflow.
